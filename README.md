# Personal Profile

A Flutter-based personal profile application developed as part of **Midterm Laboratory Activity 2** for Mobile Application Development. It presents personal information and profile details through a simple and organized mobile application interface.

## Live Demo

Explore the deployed application:

**[Personal Profile – Live Website](https://itskaiworks.github.io/personal-profile/)**

---

## Overview

Personal Profile is a Flutter application created to demonstrate fundamental mobile application development concepts while building a digital representation of a personal profile.

The project serves as an introduction to Flutter UI development, Dart programming, and organizing application components.

## Features

- **Personal Information** – Presents personal profile details.
- **Profile Interface** – Organizes profile content in a structured application layout.
- **Flutter UI Components** – Demonstrates the use of Flutter widgets to build the interface.
- **Responsive Layout** – Supports different screen sizes through Flutter's layout system.

## Technologies Used

- **Flutter** – Mobile application development framework
- **Dart** – Primary programming language
- **Material Design** – UI components and design elements
- **Git & GitHub** – Version control and source code hosting
- **GitHub Pages** – Web deployment
